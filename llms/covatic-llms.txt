# Covatic

> Covatic is a UK-based, B Corp certified advertising technology company providing privacy-preserving audience intelligence and addressability for media owners, broadcasters, publishers, and advertisers. Its platform uses on-device (edge) processing to build audience segments and demographic cohorts without third-party cookies, shared user IDs, or personal data leaving the device.

Covatic delivers "ID-less targeting, without ID-loss." Client data is stored in EU, AU, or US regions per client requirements. Integration is available three ways: the Covatic Tag (no-code tag manager), the Covatic SDK (on-device processing), and a server-to-server Covatic API.

Generated by API Evangelist from Covatic's public surface, 2026-08-12. Covatic does not publish an llms.txt of its own.

## API

Covatic serves a complete, public, unauthenticated OpenAPI 3.1.0 document for the API behind its client platform — 71 paths, 89 operations, 78 component schemas, every operation summarised and tagged. It is not linked from covatic.com; it was found on the API host itself.

- [Covatic Audience Builder API — OpenAPI](https://prodaudiencebuilderapi.covatic.io/openapi.json): OpenAPI 3.1.0, `info.title` "Audience builder". Served with no `servers[]` block; the production base is `https://prodaudiencebuilderapi.covatic.io`.
- [Swagger UI](https://prodaudiencebuilderapi.covatic.io/docs): interactive reference.
- [ReDoc](https://prodaudiencebuilderapi.covatic.io/redoc): reference rendering.

Resource families: Profiles (audience profiles), Traits, Event Traits, Retargeting Traits, Campaigns, Insights, Tags, Notes, Users, Company, Commons, Seeders, QA and Debug, plus three AI operations — Audience Builder, Audience Builder Agent (`/api/v1/ai_audience_agent/chat`) and a ChatGPT completions proxy.

Authentication is HTTP Bearer with an AWS Cognito (OIDC) JWT; the user pool is `eu-west-2_mQWqhJueg` and its discovery document is live. There is no public sign-up — Covatic provisions accounts.

What the API does NOT have, verified by probe on 2026-08-12: no idempotency key on any of the 28 POST operations, no rate-limit headers and no published limits, no request-id header, no declared error responses other than 422, no MCP server, no A2A agent card, no `/.well-known/` document on any Covatic host, no status page, no changelog, no public pricing, and no client library in any public package registry.
